## Завдання 1. Дослідження мережі

**Команда:**

```bash
ip a
```

### Результат виконання

### Результат виконання команди `ip a`

```text
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536
    inet 127.0.0.1/8 scope host lo
    inet6 ::1/128 scope host

2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    link/ether 08:00:27:1c:10:82
    inet 10.0.2.15/24 brd 10.0.2.255 scope global dynamic
```

### Аналіз мережевих параметрів

| Параметр | Значення |
|---|---|
| Інтерфейс | enp0s3 |
| Тип підключення | Віртуальний Ethernet |
| Стан | UP |
| MAC-адреса | 08:00:27:1c:10:82 |
| IPv4-адреса | 10.0.2.15 |
| Маска | 255.255.255.0 (/24) |
| Адреса мережі | 10.0.2.0 |
| Broadcast | 10.0.2.255 |
| Діапазон hosts | 10.0.2.1–10.0.2.254 |
| Кількість адрес для вузлів | 254 |
| Gateway | Буде визначено командою ip r |

### Рівні моделі OSI

- **Рівень 2 (канальний):** MAC-адреса використовується для адресації в межах канального сегмента мережі.
- **Рівень 3 (мережевий):** IPv4-адреса та маска підмережі використовуються для логічної адресації та визначення належності вузла до мережі.

### Пояснення

Команда `ip a` показала два мережеві інтерфейси: `lo` та `enp0s3`. Інтерфейс `lo` призначений для внутрішнього обміну даними комп'ютера із самим собою. Інтерфейс `enp0s3` є активним віртуальним Ethernet-адаптером Ubuntu у VirtualBox.

Локальна IPv4-адреса — `10.0.2.15`, маска — `/24`. Позначка `dynamic` вказує, що адресу призначено динамічно. Мережа має адресу `10.0.2.0`, а широкомовна адреса — `10.0.2.255`.

Шлюз за замовчуванням визначимо під час дослідження маршрутизації.
