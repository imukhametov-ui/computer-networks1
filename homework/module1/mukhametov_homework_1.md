## Завдання 1. Дослідження мережі

**Команда:**

```bash
ip a
```

### Результат виконання

### Результат виконання команди `ip a`

```text
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536
    inet 127.0.0.1/8 scope host lo
    inet6 ::1/128 scope host

2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    link/ether 08:00:27:1c:10:82
    inet 10.0.2.15/24 brd 10.0.2.255 scope global dynamic
```

### Аналіз мережевих параметрів

| Параметр | Значення |
|---|---|
| Інтерфейс | enp0s3 |
| Тип підключення | Віртуальний Ethernet |
| Стан | UP |
| MAC-адреса | 08:00:27:1c:10:82 |
| IPv4-адреса | 10.0.2.15 |
| Маска | 255.255.255.0 (/24) |
| Адреса мережі | 10.0.2.0 |
| Broadcast | 10.0.2.255 |
| Діапазон hosts | 10.0.2.1–10.0.2.254 |
| Кількість адрес для вузлів | 254 |
| Gateway | Буде визначено командою ip r |

### Рівні моделі OSI

- **Рівень 2 (канальний):** MAC-адреса використовується для адресації в межах канального сегмента мережі.
- **Рівень 3 (мережевий):** IPv4-адреса та маска підмережі використовуються для логічної адресації та визначення належності вузла до мережі.

### Пояснення

Команда `ip a` показала два мережеві інтерфейси: `lo` та `enp0s3`. Інтерфейс `lo` призначений для внутрішнього обміну даними комп'ютера із самим собою. Інтерфейс `enp0s3` є активним віртуальним Ethernet-адаптером Ubuntu у VirtualBox.

Локальна IPv4-адреса — `10.0.2.15`, маска — `/24`. Позначка `dynamic` вказує, що адресу призначено динамічно. Мережа має адресу `10.0.2.0`, а широкомовна адреса — `10.0.2.255`.

Шлюз за замовчуванням визначимо під час дослідження маршрутизації.

## Завдання 2 Дослідження маршрутизації

**Команда:**

```bash
ip r
```

### Результат виконання

```text
default via 10.0.2.2 dev enp0s3 proto dhcp metric 100
10.0.2.0/24 dev enp0s3 proto kernel scope link src 10.0.2.15 metric 100
169.254.0.0/16 dev enp0s3 scope link metric 1000
```

### Аналіз маршрутизації

| Параметр | Значення |
|---|---|
| Маршрут за замовчуванням | default |
| Шлюз (Gateway) | 10.0.2.2 |
| Мережевий інтерфейс | enp0s3 |
| Протокол отримання маршруту | DHCP |
| Локальна мережа | 10.0.2.0/24 |
| IP-адреса джерела | 10.0.2.15 |
| Метрика | 100 |

### Пояснення

Команда `ip r` відображає таблицю маршрутизації Linux.

Перший запис показує маршрут за замовчуванням через шлюз `10.0.2.2`. Якщо пакет призначений для мережі, для якої немає конкретнішого маршруту, він передається через цей шлюз.

Позначка `proto dhcp` означає, що маршрут отримано за допомогою протоколу DHCP (Dynamic Host Configuration Protocol). DHCP автоматично надає клієнту мережеві параметри, зокрема IP-адресу, маску підмережі та шлюз.

Другий запис `10.0.2.0/24` визначає безпосередньо підключену локальну мережу. Позначка `proto kernel` означає, що маршрут створено ядром Linux.

Третій запис `169.254.0.0/16` є маршрутом до діапазону локальних IPv4-адрес (link-local), які використовуються для зв'язку в межах локального каналу.

**Висновок:** Ubuntu використовує інтерфейс `enp0s3` та шлюз `10.0.2.2` для доступу до зовнішніх мереж. Маршрут за замовчуванням отримано через DHCP.
